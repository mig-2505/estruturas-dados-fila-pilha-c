# **Estrutura de Filas e Pilha em C**

## Filas em C
**Descrição de uma Fila**: Uma fila segue a lógica FIFO (First-In, First-Out): o primeiro elemento a entrar é o primeiro a sair.
É aplicada em sistemas de atendimento, buffers de impressão, filas de processos, entre outros.
Exemplo de aplicação: 
Fila de clientes em um caixa de supermercado.

**Lógica do Código Feito Sobre Fila**: 
1. enqueue → insere um elemento no final da fila.
2. dequeue → remove o elemento do início da fila.
3. mostrarFila → percorre e exibe os elementos ativos na ordem correta.

**Sobre o Código**: O código abaixo representa bem o conceito FIFO (First-In, First-Out), simulando a entrada e saída de pessoas em uma fila de atendimento.

## Pilha em C
**Descrição de uma Pilha**: Uma pilha segue a lógica LIFO (Last-In, First-Out): o último a entrar é o primeiro a sair.
É aplicada em sistemas de desfazer ações (Ctrl+Z), chamadas de funções e análise de expressões.

**Lógica do Código Feito Sobre Pilhas**:
1. push → adiciona um elemento no topo da pilha.
2. pop → remove o elemento do topo da pilha.
3. top → consulta o valor do elemento que está no topo, sem removê-lo.
4. mostrarPilha → percorre e exibe os elementos da base até o topo.

**Sobre o Código**: Esse código ilustra o conceito LIFO (Last-In, First-Out), muito usado em operações como o Ctrl+Z (desfazer) em editores de texto ou no controle de chamadas de funções em linguagens de programação.
